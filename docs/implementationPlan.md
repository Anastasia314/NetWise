### Milestone 3: Поиск и мэтчинг (Core Value)

-   [ ] **Task 3.1: Реализация логики мэтчинга в БД (FR-8)**
    -   [ ] В `app/db/queries.py` создать функцию `find_matching_users(user: User, limit: int, offset: int)`. Это самая сложная SQL-задача:
        -   [ ] Функция должна принимать "поисковые теги" текущего пользователя.
        -   [ ] Она должна найти всех других пользователей (`is_active = true`), у которых "свои теги" пересекаются с поисковыми тегами.
        -   [ ] Запрос должен исключать самого пользователя из результатов (FR-9).
        -   [ ] Запрос должен поддерживать пагинацию (`LIMIT` и `OFFSET`).

-   [ ] **Task 3.2: Реализация клавиатур для результатов поиска**
    -   [ ] В `app/keyboards/inline.py` создать функцию `get_contact_card_keyboard(user_telegram_id)`, которая возвращает кнопку `[💬 Написать]` с `url=tg://user?id=...`.
    -   [ ] В `app/keyboards/inline.py` создать функцию `get_pagination_keyboard(current_page, total_pages)`, которая возвращает кнопки `[◀️]` и `[▶️]`.

-   [ ] **Task 3.3: Реализация хендлеров для поиска (FR-7, FR-10, FR-11)**
    -   [ ] В `app/handlers/search.py` создать хендлер для команды `/search`.
    -   [ ] Хендлер вызывает `find_matching_users` с `offset=0`.
    -   [ ] Он форматирует найденные профили в виде "карточек" и отправляет первую страницу результатов с клавиатурой пагинации.
    -   [ ] Создать callback-хендлер для кнопок пагинации. Он должен парсить номер страницы из `callback_data`, заново вызывать `find_matching_users` с новым `offset` и **редактировать** исходное сообщение с новыми результатами.
